# Shelter System — Overview

> ⚠️ **THEORETICAL** — Geopolymer construction is established technology. The specific AeroCement mix design and geodesic integration require laboratory mix optimization and prototype structural testing.

The AeroCement shelter system is a lightweight geopolymer geodesic dome designed to function as both structure and thermal mass. It eliminates the separation between building envelope and energy system.

---

## Key Design Goals

| Goal | Target | Status |
|------|--------|--------|
| Thermal conductivity | 0.3–0.6 W/m·K | ❌ Mix design, not validated |
| Compressive strength | ≥15 MPa | ❌ Mix design, not validated |
| Density | 1,200–1,800 kg/m³ | ❌ Mix design, not validated |
| Embodied CO₂ | 0.1–0.2 kg/kg | ✅ Consistent with fly-ash geopolymer literature |
| Build cost (materials) | $8–25/sq ft | ❌ Site-dependent estimate |
