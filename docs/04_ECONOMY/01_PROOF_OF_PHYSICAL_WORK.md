## 7.1 The Problem

Existing cryptocurrency proof-of-work systems consume energy producing no useful physical output. Proof-of-stake concentrates governance in proportion to existing wealth. Neither mechanism rewards physical contribution to real-world infrastructure.

---

## 7.2 The Protocol

**Core mechanism:**

```
Token Issuance = f(Verified_Physical_Work, Thermodynamic_Output, Peer_Attestation)
```

Where:
- **Verified_Physical_Work** = GPS-verified labor hours + photographic documentation at each build phase
- **Thermodynamic_Output** = measured data from instrumented dome (temperature differential, Stirling output, food production)
- **Peer_Attestation** = multi-signature confirmation from existing node operators that build meets specifications

## Instrumentation Requirements

For token issuance, the following must be installed and logging:
- Interior/exterior thermocouple pair (≥15-minute interval)
- Chimney air temperature sensor
- Supply air temperature/humidity sensor
- Stirling output power meter
- Water consumption meter (evaporative system)
- GPS-tagged photographic documentation (≥weekly)
