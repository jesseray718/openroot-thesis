# Token Economy — Overview

The AeroCement token economy is a **Proof-of-Physical-Work (PoPW)** protocol that anchors cryptographic token issuance to verifiable physical labor and instrumented measurements on real AeroCement infrastructure.

It solves a core problem: existing proof-of-work systems produce no useful physical output. PoPW rewards actual construction and food production.

---

## Four Token Classes

| Token | Backed By | Supply |
|-------|-----------|--------|
| BUILD | Verified dome construction milestones | 1,000 per dome |
| THERM | Verified passive cooling (kWh equivalent) | Unlimited |
| HARVEST | Verified food production (kg) | Unlimited |
| SEED | Verified variety in seed bank | 100 per variety |

## Design Philosophy

> "We need a coordination mechanism that rewards people for building real things in the physical world."

The PoPW protocol is designed so that:
- Tokens are **meaningless** without verified physical work
- **No one can earn tokens by speculating** — only by building or measuring
- The more validated data the community accumulates, the more secure the protocol becomes
