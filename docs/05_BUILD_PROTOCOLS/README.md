Then read [02_BUILD_SEQUENCE.md](02_BUILD_SEQUENCE.md) for the complete step-by-step construction protocol.

---

## Safety Note

This is a structural building system. Dome construction requires:
- Qualified structural engineer review for any span >6m
- Geotechnical assessment for foundation design in unknown soils
- Local building permit compliance
- Competent construction supervision

**Do not build from this document alone without consulting local professionals.**
