# Aquaponics Integration — Section 5.3

> ⚠️ **THEORETICAL** — Aquaponics is a proven technology. The specific integration with quail waste input and gravity-fed Stirling-powered pumping is the novel aspect requiring management validation.

*From THESIS.md Section 5.3*

---

## System Design

**Coupled aquaponics combining:**
- Tilapia (*Oreochromis niloticus*) — hardy, fast-growing, tolerant of high density
- Leafy greens and herbs in floating raft (NFT or DWC) beds
- Quail waste liquid as supplementary ammonia source

---

## Nitrogen Cycle

```
Quail Waste → NH₃ ─┐
                    ├→ Nitrosomonas → NO₂⁻ → Nitrobacter → NO₃⁻ → Plant Uptake
Fish Waste  → NH₃ ─┘
```

---

## Target System Size (Family of 4)

| Component | Size/Count |
|-----------|-----------|
| Fish tank | 2,000–4,000 L |
| Grow beds | 20–40 m² |
| Fish stocking | 40–80 tilapia |
| Harvest cycle | 6–9 months |

**Target yields:**
- Fish: 15–25 kg/month
- Leafy greens: 200–400g/day

---

## Energy Input

Target: gravity-fed or air-lift pump driven by Stirling engine output.  
Estimated pump power: 50–150W.

---

## Water Efficiency

Aquaponics uses **90–95% less water** than soil agriculture for equivalent yield (Somerville et al., FAO 2014). This is critical in arid deployment contexts.

---

## Startup Protocol

⚠️ **Biological cycle must be established before stocking fish.**

1. Fill tank, add beneficial bacteria inoculant
2. Run nitrogen cycle for minimum 4–6 weeks (monitor NH₃, NO₂⁻, NO₃⁻)
3. Stock plants when cycle is confirmed stable
4. Stock fish after plant establishment
5. Add quail waste input gradually after system stabilizes
